# Jack Visas — jackvisas.com.mx

Sitio web estático responsive para el negocio de gestión y asesoría de visas americanas de turismo.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive.
- `assets/promocional-jack-visas.jpg` — imagen promocional proporcionada por el cliente.

## Publicación
Puedes subir estos archivos a cualquier hosting estático o al administrador de archivos de tu hosting.
El botón “Llena tu solicitud de visa” apunta al sitio oficial de DS-160:
https://ceac.state.gov/genniv/

## Pendientes recomendados antes de publicar
- Sustituir el enlace de Facebook `#` por la URL real de la página.
- Confirmar teléfono/WhatsApp.
- Definir si se mostrarán precios y, en ese caso, actualizar los importes vigentes.
- Configurar el dominio `jackvisas.com.mx` y HTTPS en el proveedor de hosting.
